WordPress.org Plugin Assets
============================

This folder contains assets for the WordPress.org plugin directory.
These files are uploaded to the /assets/ directory in the SVN repository.

Required Files:
---------------
icon-128x128.png     - Plugin icon (128x128 pixels)
icon-256x256.png     - Plugin icon HiDPI (256x256 pixels)

Optional Files:
---------------
banner-772x250.png   - Plugin banner (772x250 pixels)
banner-1544x500.png  - Plugin banner HiDPI (1544x500 pixels)
screenshot-1.png     - Screenshots referenced in readme.txt
screenshot-2.png     - (numbered sequentially)
...

Icon Guidelines:
----------------
- Use PNG format with transparency if needed
- Keep design simple and recognizable at small sizes
- Avoid text in icons (not readable at small sizes)
- Use your brand colors consistently

Banner Guidelines:
------------------
- Use PNG or JPG format
- Banner appears on your plugin's directory page
- Left side may be covered by plugin icon on some views
- Keep important content centered or right-aligned
